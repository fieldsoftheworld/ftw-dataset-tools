# Bundled crop code lists

- `fiboa/`: code lists with HCAT3 columns from https://fiboa.org/code/
  ([fiboa/fiboa.github.io](https://github.com/fiboa/fiboa.github.io) `code/`, commit `14e6714`).
- `eurocrops/` and `HCAT3.csv`: country mappings and the HCAT3 core list from
  [EuroCrops](https://github.com/maja601/EuroCrops) (commit `b4331ad`), CC-BY-SA-4.0,
  Schneider et al., "EuroCrops: The Largest Harmonized Open Crop Dataset Across the European Union".
